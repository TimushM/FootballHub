# FootballHub
Tento program je určený pre futbalových fanúšikov, aby mohli sledovať svoje obľúbené kluby a národné reprezentácie, ako aj prehliadať štatistiky a výsledky zápasov. Pomocou nášho programu si tiež budete môcť prezrieť profily futbalistov, ich štatistiky a nadchádzajúce zápasy. Okrem toho budete môcť sledovať prestupy hráčov do nových klubov.
